# გამარჯვების სახლი · 3D მაკეტი

მოდელი აგებულია ფაილებიდან **„დავით კვარაცხელია - ტექნიკური ნახაზები.pdf“** (Irakli Jokhadze Design Studio,
9 ფურცელი A.8–A.16) და **„დავით კვარაცხელია რენდერები.pdf“** (8 გვერდი — მხოლოდ მასალები და ფერები).
მასშტაბი: **1 ერთეული = 1 მეტრი**, Y ღერძი ზემოთ.

## ფაილები

| | ფაილი | რა არის |
|---|---|---|
| A | `dist/branch-viewer.html` | ინტერაქტიული სანახავი — ერთი ფაილი, ყველაფერი ჩაშენებულია |
| B | `dist/branch-model.glb` | 3D მოდელი სხვა პროგრამებისთვის (Blender, SketchUp, 3ds Max, Windows 3D Viewer…) |
| C | `src/`, `tools/` | საწყისი კოდი (იხ. ქვემოთ) |
| D | `README.md` | ეს ინსტრუქცია |
| — | `verification/` | შემოწმების სურათები (ხედები; PDF-ის გეგმა და მოდელის კონტური ერთმანეთზე) |

საწყისი კოდი:

- `src/config.js` — **ყველა ზომა**: სიმაღლეები (`H`), ფერები/მასალები, კედლები, ღიობები, კარის ფრთები, ოთახები, საფეხურები, სახურავი, ზომების ხაზები;
- `src/furniture-data.js` — ავეჯის კონტურები, სიმაღლეები და PDF-ის კოდები (F1…F9);
- `src/model.js` — გეომეტრიის აგება (მხოლოდ three.js, მუშაობს ბრაუზერშიც და Node-შიც);
- `src/viewer.js`, `src/index.html` — ინტერფეისი;
- `tools/build.mjs` → HTML, `tools/export-glb.mjs` → GLB (+ შემოწმება), `tools/serve.mjs` → ლოკალური სერვერი.

ხელახლა აწყობა (საჭიროა Node.js 18+):

```
npm install
npm run build
```

ზომის შეცვლა: შეასწორეთ `src/config.js` ან `src/furniture-data.js` და გაუშვით `npm run build` — განახლდება ორივე ფაილი.
ყველა ზომა იქ მილიმეტრებშია, გეგმის კოორდინატებში (x — აღმოსავლეთისკენ, y — სამხრეთისკენ, z — სიმაღლე იატაკიდან).

## გახსნა

- **branch-viewer.html** — უბრალოდ გახსენით ორჯერ დაწკაპუნებით (Chrome, Edge, Firefox, Safari).
  Three.js და გეომეტრია ფაილშივეა: **ინტერნეტი და ლოკალური სერვერი არ სჭირდება**. საჭიროა WebGL (ნებისმიერი თანამედროვე ბრაუზერი).
- **branch-model.glb** — Blender: *File → Import → glTF 2.0*; Windows-ზე იხსნება „3D Viewer“-შიც.
  ერთეული — მეტრი. სათავე (0, 0, 0) — სახლის **ჩრდილო-დასავლეთის გარე კუთხე**, სუფთა იატაკის დონეზე (±0.000);
  X — აღმოსავლეთისკენ, Z — სამხრეთისკენ (ტერასიდან შესასვლელისკენ), Y — ზემოთ.

ღილაკები: **საწყისი ხედი** (ზემოდან დახრილი, ჭერის გარეშე), **მთლიანი სახლი**, **ზედხედი** (ორთოგრაფიული, PDF-ის
ორიენტაციით — ტერასა ზემოთ), **3D ხედი**, **წინა ხედი** (ტერასის ფასადი), **გვერდხედი** (დასავლეთიდან), **ზუმი + / −**,
**სრული ეკრანი**, ფენები **ჭერი**, **გარე კედლები** (შიდა ტიხრები რჩება), **ავეჯი**, **ზომები**, და **GLB-ის ჩამოტვირთვა**.

ობიექტზე დაჭერისას ბარათში ჩანს სახელი, კოდი და ზომები. ყოველ ზომას აქვს ნიშანი:

- **PDF** — რიცხვით წერია PDF-ში;
- **≈ ნახაზიდან** — რიცხვი არ წერია, მაგრამ ზუსტად ამოღებულია PDF-ის ვექტორული ხაზებიდან;
- **რენდერიდან** — მხოლოდ რენდერებზეა (ფერი, მასალა, ფასადის პანელი);
- **ვარაუდი** — PDF-ში არ არის, აღებულია გონივრული მნიშვნელობა.

ზომების რეჟიმში მუქი უწყვეტი ხაზი = PDF-ში მითითებული, ნარინჯისფერი წყვეტილი = ნახაზიდან გაზომილი ან სავარაუდო.
ჩანს ოთახების სახელები და ფართობები (PDF-დან).

**GLB-ის ჩამოტვირთვა** ყოველთვის ინახავს სრულ მოდელს — დამალული ფენების ჩათვლით. ზომები, მიწა და მონიშვნა მასში არ შედის.
GLB-ის ჯგუფები: `Site_Plinth_Terrace_Steps`, `Floors`, `Walls_Exterior`, `Walls_Interior`, `Furniture`, `Ceiling_Roof`;
ობიექტების სახელები — როგორც config-ში (`W-N1`, `C-02`, `P-12`, `F4`, `BED-02`…), დამატებითი ინფორმაცია — glTF extras-ში.
