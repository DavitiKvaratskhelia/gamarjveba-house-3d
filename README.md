# გამარჯვების სახლი · 3D მაკეტი

მოდელი აგებულია ფაილებიდან **„დავით კვარაცხელია - ტექნიკური ნახაზები.pdf“** (Irakli Jokhadze Design Studio,
9 ფურცელი A.8–A.16) და **„დავით კვარაცხელია რენდერები.pdf“** (8 გვერდი — მხოლოდ მასალები და ფერები).
მასშტაბი: **1 ერთეული = 1 მეტრი**, Y ღერძი ზემოთ.

## ფაილები

| | ფაილი | რა არის |
|---|---|---|
| A | `dist/branch-viewer.html` | ინტერაქტიული სანახავი — ერთი ფაილი, ყველაფერი ჩაშენებულია |
| B | `dist/branch-model.glb` | 3D მოდელი სხვა პროგრამებისთვის (Blender, SketchUp, 3ds Max, Windows 3D Viewer…) |
| C | `src/`, `tools/` | საწყისი კოდი (იხ. ქვემოთ) |
| D | `README.md` | ეს ინსტრუქცია |
| — | `verification/` | შემოწმების სურათები (ხედები; PDF-ის გეგმა და მოდელის კონტური ერთმანეთზე) |

საწყისი კოდი:

- `src/config.js` — **ყველა ზომა**: სიმაღლეები (`H`), ფერები/მასალები, კედლები, ღიობები, კარის ფრთები, ოთახები, საფეხურები, სახურავი, ზომების ხაზები;
- `src/furniture-data.js` — ავეჯის კონტურები, ზომები, რენდერის პარამეტრები და PDF-ის კოდები (F1…F9);
- `src/furniture.js` — ავეჯის 3D ამგებები და მასალები, `src/textures.js` — პროცედურული ფაქტურები, `src/ref-views.js` — რენდერებთან შედარების კამერები;
- `INVENTORY.md` — რენდერების ავეჯის სრული სია (ოთახი, რენდერი, ობიექტი, მასალა, რა არის დადასტურებული).
- `src/model.js` — გეომეტრიის აგება (მხოლოდ three.js, მუშაობს ბრაუზერშიც და Node-შიც);
- `src/viewer.js`, `src/index.html` — ინტერფეისი;
- `tools/build.mjs` → HTML, `tools/export-glb.mjs` → GLB (+ შემოწმება), `tools/serve.mjs` → ლოკალური სერვერი.

ხელახლა აწყობა (საჭიროა Node.js 18+):

```
npm install
npm run build
```

ზომის შეცვლა: შეასწორეთ `src/config.js` ან `src/furniture-data.js` და გაუშვით `npm run build` — განახლდება ორივე ფაილი.
ყველა ზომა იქ მილიმეტრებშია, გეგმის კოორდინატებში (x — აღმოსავლეთისკენ, y — სამხრეთისკენ, z — სიმაღლე იატაკიდან).

## გახსნა

- **branch-viewer.html** — უბრალოდ გახსენით ორჯერ დაწკაპუნებით (Chrome, Edge, Firefox, Safari).
  Three.js და გეომეტრია ფაილშივეა: **ინტერნეტი და ლოკალური სერვერი არ სჭირდება**. საჭიროა WebGL (ნებისმიერი თანამედროვე ბრაუზერი).
- **branch-model.glb** — Blender: *File → Import → glTF 2.0*; Windows-ზე იხსნება „3D Viewer“-შიც.
  ერთეული — მეტრი. სათავე (0, 0, 0) — სახლის **ჩრდილო-დასავლეთის გარე კუთხე**, სუფთა იატაკის დონეზე (±0.000);
  X — აღმოსავლეთისკენ, Z — სამხრეთისკენ (ტერასიდან შესასვლელისკენ), Y — ზემოთ.

## მართვა — სამი რეჟიმი (v3)

ქვედა ზოლში: **Orbit / Walk / Plan** გადამრთველი, **საწყისი** (Home), **მთლიანი** (Fit to View), **ფოკუსი**,
**სრული ეკრანი** და **დახმარება** (ტელეფონზე ბოლო ორი და დანარჩენი პარამეტრები — ღილაკ **„მეტი“**-ს პანელში).
მარჯვენა პანელი (ფენები, შედარების ხედები, თბილი განათება, GLB) უცვლელია.

**Orbit — სივრცის გარედან**

| მოქმედება | კომპიუტერი | ტელეფონი / ტაბლეტი |
|---|---|---|
| ტრიალი | მარცხენა ღილაკით გადათრევა | ერთი თითით გადათრევა |
| გადაადგილება (pan) | მარჯვენა ღილაკით გადათრევა | ორი თითით გადათრევა |
| ზუმი | ბორბალი / trackpad (კურსორისკენ) | ორი თითის გაშლა / შეკუმშვა |
| ინფორმაცია / ფოკუსი | დაჭერა / ორჯერ დაჭერა ან **F** | შეხება / ორმაგი შეხება |

ზუმის ზღვარი მოდელის ზომაზეა მორგებული (0.6 მ … მთლიანი სახლის ხედის 2×), ბრუნვის ცენტრი მოდელის არეს ვერ ცდება,
კამერა იატაკის / მიწის ქვემოთ ვერ ჩადის. Focus-ის შემდეგ ბრუნვის ცენტრი = არჩეული ობიექტი.

**Walk — სივრცეში სიარული** (თვალის სიმაღლე 1.65 მ, იწყება შესასვლელთან)

| მოქმედება | კომპიუტერი | ტელეფონი / ტაბლეტი |
|---|---|---|
| სიარული | **W A S D** ან ისრები; **Shift** — სწრაფად | ვირტუალური ჯოისტიკი (ქვედა მარცხენა კუთხე) |
| მიხედვა | მაუსით გადათრევა; ან **„მაუსით ხედვა“ / L** — მაუსის ჩაკეტვა (Esc — გათავისუფლება) | ეკრანზე თითით გადათრევა (ჯოისტიკთან ერთად, სხვა თითით) |
| ინფორმაცია | დაჭერა (ჩაკეტვისას — ეკრანის ცენტრის ჯვრის ქვეშ) | შეხება |
| F / ფოკუსი | მონიშნული ობიექტისკენ შებრუნება | იგივე |

კამერა მოძრაობს მხოლოდ იატაკის სიბრტყეზე (ზემოთ ყურება არ აწევს), კედლებში, მინებში, დაკეტილ კარებში და მსხვილ ავეჯში ვერ გადის
და კედლის გასწვრივ სრიალებს (სხეული — ცილინდრი Ø0.44 მ; დამაბრკოლებლები — გამარტივებული ფორმები 1 მ-იან ბადეში).
მცირე და მაღლა ჩამოკიდებული ნივთები (თაროები, ტელევიზორები, სარკეები ჭერთან) გავლას არ ბლოკავს. რყევა / ნაბიჯების ეფექტი არ არის.
სიარული შესაძლებელია ყველა ოთახში, ტერასაზე და შესასვლელის მოედანზე; საშხაპეები დაკეტილი მინის მიღმაა.

**Plan — ზედხედი**: ორთოგრაფიული კამერა, ჩრდილოეთი (ტერასა) ზემოთ — ორიენტაცია არ იცვლება; გადათრევა (ან 1 თითი) — გადაადგილება,
ბორბალი (ან 2 თითი) — ზუმი. ჭერი დროებით იმალება და რეჟიმიდან გასვლისას წინა მდგომარეობა ბრუნდება.

**Home** — მიმდინარე რეჟიმის საწყისი ხედი (მხოლოდ კამერა). **Fit** — მთელი სივრცე კადრში (Walk-იდან — გადასვლა Orbit-ზე).
რეჟიმებს შორის გადასვლა ≈0.5 წმ; ნებისმიერი ახალი მოქმედება ანიმაციას წყვეტს. თითოეული რეჟიმის ბოლო პოზიცია სესიაში ინახება.
„შემცირებული მოძრაობის“ (prefers-reduced-motion) პარამეტრზე გადასვლები მყისიერია და ინერცია გამორთულია.

ობიექტზე დაჭერისას ბარათში ჩანს სახელი, კოდი და ზომები. ყოველ ზომას აქვს ნიშანი:

- **PDF** — რიცხვით წერია PDF-ში;
- **≈ ნახაზიდან** — რიცხვი არ წერია, მაგრამ ზუსტად ამოღებულია PDF-ის ვექტორული ხაზებიდან;
- **რენდერიდან** — მხოლოდ რენდერებზეა (ფერი, მასალა, ფასადის პანელი);
- **ვარაუდი** — PDF-ში არ არის, აღებულია გონივრული მნიშვნელობა.

ზომების რეჟიმში მუქი უწყვეტი ხაზი = PDF-ში მითითებული, ნარინჯისფერი წყვეტილი = ნახაზიდან გაზომილი ან სავარაუდო.
ჩანს ოთახების სახელები და ფართობები (PDF-დან).

**GLB-ის ჩამოტვირთვა** ყოველთვის ინახავს სრულ მოდელს — დამალული ფენების ჩათვლით. ზომები, მიწა და მონიშვნა მასში არ შედის.
GLB-ის ჯგუფები: `Site_Plinth_Terrace_Steps`, `Floors`, `Walls_Exterior`, `Walls_Interior`, `Furniture`, `Ceiling_Roof`;
ობიექტების სახელები — როგორც config-ში (`W-N1`, `C-02`, `P-12`, `F4`, `BED-02`…), დამატებითი ინფორმაცია — glTF extras-ში.
